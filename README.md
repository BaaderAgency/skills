# Baader skills

Free Claude Code skills from [Baader](https://baaderagency.com). One folder per skill, each with its own
README and install steps. Also listed in the skills library at https://baaderagency.com/skills.

| Skill | What it does |
|---|---|
| [hookhoard](hookhoard/) | Build and break down mood boards and swipe files from your AI chat (needs the HookHoard Chrome extension). |
| [effort-loop](effort-loop/) | Build on low, verify on high: a cheap builder subagent, a fresh high-effort verifier with held-out tests. |
